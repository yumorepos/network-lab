# W1.4: Version 1 baseline freeze

**Purpose.** Version 1 baseline before the demand model redesign. Every Phase 6
change is measured against the numbers in this document.

**Frozen at.** commit `bd7d4dd07d3bddfd8c35e644272f32db23fa7684`
(`phase5/milestone-a-integrity`), 2026-07-28, working tree clean.

---

## Scope note: this is an artifact baseline, not a performance baseline

PHASE_5_6_PLAN.md W1.4 specified a decision replay producing four metric
families (agreement with operator, survival, right-sizing, incremental value
over demand rank). **That replay is not implemented and is not in this freeze.**

What is frozen here is the full set of computed artifacts plus their fingerprints
and the fit diagnostics of the models that produced them. That supports two of
the three kinds of before-and-after a Phase 6 change needs:

| comparison type | supported by this freeze? |
|---|---|
| Did the artifacts change, and which markets moved? | **Yes** |
| Did model fit improve (predicted over observed by size band, holdout APE)? | **Yes** |
| Did predictive skill on real launches improve? | **No.** Needs the W1.4 replay. |

This matters less for the demand redesign than it would for a competition or
verdict change. The redesign's success criterion is a **fit** criterion,
measurable directly against observed demand without any route-outcome data. The
gap becomes binding for W2.4 QSI calibration and for any change to the verdict
thresholds, neither of which should start before the replay exists.

## Known limitations at freeze

Carried forward deliberately, not fixed.

1. **Gravity size bias**, the subject of Phase 6. See
   `docs/change_reports/A5_canadian_demand_diagnostic.md`.
2. **The cap reports a bound as a point estimate.** Statistically valid as an
   upper bound; wrong as an estimate. Decision-relevant: removing it would put 1
   WestJet and 3 Porter markets over the hurdle.
3. **11 point-in-time leakage vectors**, 3 severe. See
   `docs/W1.3_point_in_time_audit.md`. The backtest is a single fixed-vintage
   model and its covariates are current-vintage.
4. **No predictive-skill baseline.** The W1.4 decision replay is not built.
5. **Competition reconstruction is unvalidated against observed itineraries.**
   DB1B Coupon is not ingested. QSI weights are asserted, not fitted.
6. **Air Canada connecting itineraries are structurally invisible** out of
   Canadian hubs (LIMITATIONS item 14).
7. **Cost layer has no external validation.** US comparator proxy plus a flat
   fee proxy at low confidence.
8. **Hub income is a destination-income proxy** in `demand.py`, doubling the
   destination-income elasticity, because `dim_metro_ca` has no income column.
9. **Register selection bias.** 74 hand-compiled rows skewed to newsworthy
   carriers; the derived 89,502-spell register is not yet wired into the
   backtest.

## Reproducibility evidence

```
make test              38 passed
make reproducibility   reproducible: 25 artifacts identical across a warehouse rebuild
```

The reproducibility gate rebuilds the DuckDB marts from cached Parquet, re-runs
the models and the backtest, and compares every artifact order-insensitively,
including YAML and CSV. It exists because two non-determinism defects (a StatCan
CMA prefix match and a CBSA-to-city-market `dict()`) produced plausible wrong
numbers that only moved on a rebuild, which `make test` could not see. A third
(`string_agg` without `ORDER BY`) and a fourth (the same CMA prefix join in the
backtest) were caught by the gate itself.

**Caveat on the word clean.** The gate rebuilds marts from cached Parquet. It
does not re-download from BTS, StatCan, BEA or EIA, so it proves the
warehouse-to-model boundary is deterministic, not that the ingest layer is. A
full cold `make data` reproduction has not been run and upstream sources revise.
